- **依赖**：T00、T02、T08、T14/T15 的测量（按实际启动情况）；真实流量、延迟、成本或配额证据达到事先确定的触发条件。
- [ ] 触发前只采样和记录，不为了“静态更快”改造现有架构。
- [ ] 触发后单独设计语言变体、匿名/登录边界、隐藏状态变更和发布失效策略。
- [ ] 明确 HTTP 页面缓存、D1 Markdown 渲染缓存、静态资源缓存三者不同职责。

- **验收**：有量化收益依据和隔离/失效测试；没有触发证据时维持暂缓即为正确处理，不将该项算作接入未完成。

## 统一验收要求

### 自动化入口

```bash
npm run lint
npx tsc --noEmit
npm test
npm run build
# Linux / 兼容 CI：
npm run build:worker
```

仅在目标数据库明确时运行迁移；不要把 `db:migrations:apply`（远端）放进日常无条件测试命令。新增测试仍使用项目现有工具为主，按切片补足缺口。

### 最小行为矩阵

| 路径 | 正常场景 | 高价值错误/边界 |
| --- | --- | --- |
| 会话 | 正确口令、持久会话、登出 | 错误口令、第五次失败、损坏/过期 Cookie |
| 文章 | 新建、编辑、改名、导出、删除 | slug 冲突、中途 DB 失败、交错写入 |
| 可见性 | 公开→隐藏→重新公开 | 缺列、未登录直链、评论/统计泄漏 |
| API | JSON/Markdown、显式 slug 更新 | 畸形 JSON、空/超限正文、过期/删除 Token |
| 渲染 | 代码、公式、目录、图片 | 恶意 HTML、版本失效、冷缓存、损坏 TOC |
| 编辑 | 普通/沉浸、工具栏、撤销/重做 | 网络失败、会话过期、中文输入、离开未保存 |
| 迁移 | 空库、旧库、重复执行 | 历史缺记录、清空迁移、失败恢复 |
| 展示 | 中英、明暗、移动/桌面 | 长标题、空数据、键盘、触摸、reduced-motion |

## 重要决定

### 文档统一而不移动运行目录

status: accepted

依据为用户要求先按 harness-run 规范项目。保持 Next、OpenNext、Wrangler 和迁移实际入口不变；旧资料合并到架构/design/history，TODO 只在此计划维护。根目录另建 TODO 的初始提议不再采用。

### 先可靠性，后性能和新增功能

status: proposed

按静态分析建议优先处理数据一致性、可见性和恢复能力；后续顺序可随真实基线及用户目标调整，不构成当前实施承诺。

### 保留低流量条件下的缓存暂缓决定

status: accepted

来源是既有修复历史，不是本轮新增用户承诺。维持 T20 暂缓；真实指标或用户新目标出现时再记录替代决定。T06 的缓存版本正确性、T07 的信任边界和 T08 的测量不等于授权全站缓存改造。
