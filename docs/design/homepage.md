## 音乐

配置入口：`src/lib/home-music.ts` 的 `HOME_MUSIC`。

- `title` / `artist`：真实曲名与演奏者。
- `src`：同站音频路径或明确的 HTTP(S) 地址；留空则禁用播放并说明未配置。
- `sourceUrl`：作品和许可来源。
- `credit` / `creditUrl`：录音方署名与链接。

当前音频为贝多芬《月光奏鸣曲》第一乐章，Paul Pitman 为 Musopen 演奏；MP3 位于 `public/audio/moonlight-sonata-paul-pitman.mp3`，约 6.85 MiB。来源、公共领域声明、署名要求和校验值见[音频授权说明](../../public/audio/LICENSE.md)。不得使用旧占位曲名“月亮之矢”冒充这首录音。

播放器嵌入原状态胶囊，收起行高为 16px，与原文字行对齐；详细面板绝对定位，不进入文档流，展开/收起均不推低足迹。支持点击外部或 Esc 收起、播放/暂停、时间进度、音量、加载/错误/重试/结束和来源署名。音乐状态提示不额外撑高胶囊。

不自动播放，`preload="none"`；访客主动点击后才请求音频。离开首页暂停并卸载，不承诺跨页面续播。没有歌词抓取、假频谱、第三方音频 SDK 或跟踪。

更换录音必须保有分发许可并更新授权记录。`next.config.ts` 的 `media-src` 默认只允许同站，使用外部音频时仅加入配置来源的 origin；不放宽脚本和连接策略。配置变化需重新构建。

## 粒子背景

保留原 `dither-background-wrapper` 的全宽、100vh、高度及层级，不修改首页结构。`HomeBackground` 在容器内提供静态纹理和 WebGL 回退；桌面且未要求减少动效时挂载动态背景。

- 单通道原生 WebGL 噪声波纹和有序像素颗粒，保留明显的颗粒强度；不用 Three.js/fiber/后处理加载背景。
- 波幅参数实际参与位移，鼠标扰动平滑且限制在背景范围内。
- 像素比 1；离屏、文档隐藏时停止帧调度，恢复时不补算离开期间时间；静态模式不持续调度帧。
- 手机和 reduced-motion 使用静态颗粒。WebGL 创建失败或上下文丢失时保留静态背景。
- 不承诺 Next 完全不预取小型动态 chunk。原标题的 GSAP/Shuffle 动画已恢复，不能再宣称首页完全不加载 GSAP。
