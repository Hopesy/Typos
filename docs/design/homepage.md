## 顶部导航：三段中轴

2026-11-22 用户从 20 个原型方向中选择“先试一下三段中轴”，当前为本地试用。

- 标准导航以完整 TYPOS 字标、五个栏目、语言/主题/后台组成三段。左右使用等宽网格，栏目相对页面独立居中；沿用首页、合集及页脚的 `container max-w-5xl px-4`，容器上限 1024px、内部内容上限 992px，字标与工具组分别对齐正文左右边缘。
- 字标返回首页；栏目为首页、合集、瞬间、日常、关于，瞬间保留新页打开；后台入口进入 `/admin`。共用 `navItems` 维护桌面与手机栏目。
- 字标宽度为桌面 112px、手机顶栏及抽屉 96px；桌面当前栏目下划线距链接底部 3px，保持与文字的紧凑关联。
- 用户反馈高度偏大后，标准桌面导航统一为 64px，手机及抽屉顶栏为 56px，内部控件保留 36px 点击区域；移除按视口高度分档的规则。首页原文字标题、动画和内容布局保持原结构。
- 语言与主题切换继续复用现有组件，标准导航使用 `appearance="plain"`；相册专用控制栏与后台沿用默认面板外观。
- 按后续视觉反馈，标准导航控件统一为 36px 高、8px 圆角，语言文字 12px、图标 16px；栏目文字 14px。用户进一步要求降低后台入口存在感，现使用低强调管理图标，默认透明底、无边框/阴影及可见文字；悬停提示和无障碍名称保留「后台 / Admin」，桌面与手机菜单共用样式。
- 手机顶栏为左字标和右侧工具/菜单，沿用抽屉导航与关闭交互，顶栏和抽屉字标左边距均为 16px；当前栏目使用 `aria-current="page"`。
- 首页导航使用透明底边框保留原高度，背景顶部通过 64–112px 的响应式透明度渐变接入颗粒纹理；其他标准页面保留细分隔线。

本地验收与后续调整见[导航方案 history](../histories/2026-11/20261122-navigation-layout-studies.md)及同一活动计划。

## 浅色配色

2026-11-22 用户否决冷白＋墨蓝试稿，提供 tweakcn 的 Claude 配色截图，并确认接续暖纸白、炭灰和陶土橙方向；当前为本地试用，冷色方案 superseded。

- 基础颜色集中维护在 `globals.css` 的浅色变量：页面按用户后续明确值使用 `#FAF9F5`、卡片/浮层 `#FFFEFB`、主文字 `#302F2B`、辅助底色 `#E9E6DC`、普通文字 `#535146`、次要文字 `#716F64`。
- `--primary` 与 `--hud-accent` 为参考中的 `#C96442`，用于当前栏目下划线、手机选中标记及中档活动格；小字号链接悬停、行内代码和目录选中使用加深的 `--hud-link: #A94F35`，保持清晰度。后台入口继续低强调灰色。
- 用户反馈显淡后，浅色当前栏目文字与阅读合集入口常态使用陶土色，当前栏目线条为 20×2px；深色仍为 16×1px。
- 足迹三个活动等级集中由 `--heatmap-low/medium/high` 维护：一次为浅橙 `#E7B39F`，两次为主色 `#C96442`，三次及以上为深棕 `#7D3522`。这是用户反馈线上多档数据区分不足后的调整，当前待视觉复看；此前一次直接使用主色、后续轻微压暗的方案 superseded。深色保持白色 10%/20%/40%，无活动格沿用原淡背景。
- 状态栏及足迹提示框使用 `--card`，文章正文、引用和代码区沿用同一暖色体系。品牌 SVG 沿用既有素材。
- 用户指出浅色粒子效果消失后，浅色 WebGL 波纹透明度恢复为 0.48，静态暖灰点阵透明度为 0.18，柔和径向底纹为 0.06；此前过度减淡到 0.12/0.07 的方案 superseded。保留顶部过渡、底部渐隐和原有内容位置；手机与减少动态模式仍显示静态颗粒。深色颜色变量及 0.78 波纹强度沿用此前设计。

## 音乐

配置入口：`src/lib/home-music.ts` 的 `HOME_MUSIC`。

- `title` / `artist`：曲名与已知作者/演奏者；缺少署名信息时省略可选字段。
- `src`：同站音频路径或明确的 HTTP(S) 地址；留空则禁用播放并说明未配置。
- `sourceUrl`：作品和许可来源。
- `credit` / `creditUrl`：录音方署名与链接。

当前音频为用户于 2026-11-22 提供并指定替换的《月亮之矢》，位于 `public/audio/yueliang-zhi-shi.mp3`，3,750,809 字节（约 3.75 MB / 3.58 MiB）、约 3 分 54 秒。文件按原始字节复制，曲名取自提供的文件名，作者/演奏者字段留空；来源与校验值见[音频来源记录](../../public/audio/LICENSE.md)。原《月光奏鸣曲》录音已从当前静态资源中替换，历史署名记录保留在同一文件及 Git 历史。

播放器直接嵌入原状态胶囊，点击曲目区即可直接播放/暂停/重试，不再使用展开悬浮窗（2026-11-20 用户明确“不需要播放悬浮窗啊”，原展开面板方案 superseded）。胶囊内仅保留紧凑单按钮（圆形播放/暂停键 + 环形进度提示 + 曲名 + 播放态微缩均衡条），行高与状态/地点文字严格居中对齐且不撑高胶囊，不推低足迹；完整曲名及可用署名统一从 `HOME_MUSIC` 读取并用于悬停提示。

加载与缓冲时通过原按钮内的转圈图标反馈，状态文字使用 `sr-only` 向读屏器提供；页面只在播放失败时显示状态文字。微缩均衡条保留固定占位，暂停、加载、播放和缓冲之间切换时，按钮与状态胶囊宽度保持一致。

不自动播放，`preload="none"`；访客主动点击后才请求音频。离开首页暂停并卸载，不承诺跨页面续播。没有歌词抓取、假频谱、第三方音频 SDK 或跟踪。

更换录音必须保有分发许可并更新授权记录。`next.config.ts` 的 `media-src` 默认只允许同站，使用外部音频时仅加入配置来源的 origin；不放宽脚本和连接策略。配置变化需重新构建。

## 粒子背景

保留原 `dither-background-wrapper` 的全宽、100vh、高度及层级，不修改首页结构。`HomeBackground` 在容器内提供静态纹理和 WebGL 回退；桌面且未要求减少动效时挂载动态背景。

- 单通道原生 WebGL 噪声波纹和有序像素颗粒，保留明显的颗粒强度；不用 Three.js/fiber/后处理加载背景。
- 波幅参数实际参与位移，鼠标扰动平滑且限制在背景范围内。
- 像素比 1；离屏、文档隐藏时停止帧调度，恢复时不补算离开期间时间；静态模式不持续调度帧。
- 手机和 reduced-motion 使用静态颗粒。WebGL 创建失败或上下文丢失时保留静态背景。
- 2026-11-22 导航接续优化在 `.home-background` 统一应用顶部渐变遮罩，静态纹理与 WebGL 一同过渡；渐变长度为 `clamp(64px, 8vw, 112px)`，保留背景尺寸、底部渐变及首页内容位置。
- 不承诺 Next 完全不预取小型动态 chunk。原标题的 GSAP/Shuffle 动画已恢复，不能再宣称首页完全不加载 GSAP。
